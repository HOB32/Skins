# ROTK developer invitation page

Static invitation/password setup page for ROTK – Skin Development Client.
Published from this repository's `main` branch root with GitHub Pages.

The page uses Supabase Auth at `joxglaohovisgqswcmga.supabase.co`. Its `config.js`
contains only the public project URL and publishable key. Do not add secret API
keys, signing private keys, launcher state or game assets to this repository.

Open the invitation or recovery link received by email to choose a password.
Launcher access still requires the project administrator's approval.

Edit the static HTML, JS and CSS here to update the page. GitHub Pages publishes
commits to `main`; no build tools, Lovable credits or server runtime are needed.
